# 人工评分说明

实际答案评分表位于`reports/experiments/generation/baseline/human_scoring_60.csv`，随60题真实答案生成。每行包含问题、参考答案、系统答案和送入模型的来源。该实验冻结真实检索结果，只测生成阶段；不能当作最新生产索引的完整端到端质量成绩。

填写真实评分人姓名，以及正确性、完整性、引用质量三个1至5分维度。流畅性为可选维度。未填写的分数保持空白，不写0，也不将模型规则检查结果当人工评分。只有评分人和三个必需维度都填写后，该样本才视为已评分。

| 分值 | 正确性 | 完整性 | 引用质量 |
| --- | --- | --- | --- |
| 5 | 核心事实与原文一致，推断有依据 | 回答全部关键点和限制条件 | 关键结论均可由对应来源支持 |
| 4 | 有轻微表述问题，核心结论正确 | 仅遗漏次要细节 | 主要结论有支持，少量定位不足 |
| 3 | 部分事实需要更正 | 回答部分关键点 | 部分引用支持不足或覆盖不全 |
| 2 | 存在影响结论的错误 | 大量关键点缺失 | 主要引用与结论不对应 |
| 1 | 核心结论错误或无依据 | 未有效回答问题 | 无可用来源或引用错误 |

先核查原文物理页，再填写分数。特别区分预训练与下游评估、准确率与错误率、不同实验条件和指标单位。问题证据与参考答案也需学生确认；`assistant_source_checked`记录表示助理核对，不是人工共识。

导入已填写的评分，生成新结果，不覆盖原始实验：

```powershell
.venv\Scripts\python.exe scripts/review_results.py reports/experiments/generation/baseline/results.json --import-csv reports/experiments/generation/baseline/human_scoring_60.csv --output reports/experiments/generation/baseline/human_reviewed_results.json
```

当前用户选择先生成表，全部人工分数留空。评测报告不得将这些空值描述成0分、满分或已完成质量验收。
