# 人工评分说明

实际答案评分表位于`reports/experiments/generation/baseline/human_scoring_60.csv`，60题已于2026-10-14填写AI辅助评分。每行包含问题、参考答案、系统答案、来源、四维分数、具体评语、问题原因和核对出处。评分人是“Codex AI辅助评分”，`grading_method=ai_assisted`。该实验冻结真实检索结果，只测生成阶段；不能当作最新生产索引的完整端到端质量成绩。

AI评分依据参考答案、对应论文原文与通用技术知识，四个维度分别评1至5分。正确性、完整性、引用质量、流畅性均值依次为3.50、2.98、3.03、4.58。逐题评语说明实际正确点、错误或遗漏，保留对参考答案和原文解释的人工复核空间。

实际人工复核时填写真实评分人姓名，将`grading_method`改为`human`，根据原文确认或修改三个必需维度及可选流畅性。只有真实人工评分人及三个必需维度填写后，该样本才视为完成人工评分；AI导入单独保存在`ai_review`，不会计入人工完成数。

| 分值 | 正确性 | 完整性 | 引用质量 |
| --- | --- | --- | --- |
| 5 | 核心事实与原文一致，推断有依据 | 回答全部关键点和限制条件 | 关键结论均可由对应来源支持 |
| 4 | 有轻微表述问题，核心结论正确 | 仅遗漏次要细节 | 主要结论有支持，少量定位不足 |
| 3 | 部分事实需要更正 | 回答部分关键点 | 部分引用支持不足或覆盖不全 |
| 2 | 存在影响结论的错误 | 大量关键点缺失 | 主要引用与结论不对应 |
| 1 | 核心结论错误或无依据 | 未有效回答问题 | 无可用来源或引用错误 |

先核查原文物理页，再填写分数。特别区分预训练与下游评估、准确率与错误率、不同实验条件和指标单位。问题证据与参考答案也需学生确认；`assistant_source_checked`记录表示助理核对，不是人工共识。

当前AI评分及统计已保存在`ai_scored_results.json`和`ai_review_summary.json`，与未经评分的`results.json`分开。人工复核后导入评分，生成新结果：

```powershell
.venv\Scripts\python.exe scripts/review_results.py reports/experiments/generation/baseline/results.json --import-csv reports/experiments/generation/baseline/human_scoring_60.csv --output reports/experiments/generation/baseline/human_reviewed_results.json
```
