# 智能科研助理技术设计

Streamlit 通过 REST/SSE 调用 FastAPI，服务组合文档导入、检索、RAG 和手写 Agent。运行数据位于 RAG_DATA_DIR，原件、SQLite、向量和日志分别持久化。

## 数据与索引

SourceBlock 保留 PDF 物理页、段落、表格和坐标；Chunk 传播来源；RetrievalHit 分别记录向量、BM25、RRF、重排分数。分块使用轻量 token，模型超长输入完整窗口聚合。RRF 以排名融合，不直接相加不可比分数。

上传按工作区和内容hash去重，原件使用服务器ID命名。单worker执行解析、分块、编码、发布；SQLite单事务提交片段、ready文档、全库版本和缓存失效。失败不作为可检索内容，重启中断任务可以重试。模型权重、分块或解析配置变化后需重建。不同Embedding fingerprint分别保存索引。

## 生成与证据

服务器建立[S1]等证据表，模型只能引用已有编号。上下文按文档轮转，保证比较证据覆盖；跨页文本标出各页，截短后同步裁剪来源。审校检查引用存在性和完整数字token支撑，不等于语义正确性证明。PDF支持原页和块坐标高亮，其他格式用段落定位。

缓存绑定索引版本、Embedding revision、模型/Prompt/检索配置、论文范围和历史。近似命中核对数值、英文锚点、否定和意图；时间、指代与计算避开复用。缓存异常不丢失完成答案。生成期间库变更会记录检索快照并提醒复核。

Ollama使用原生工具协议、流式与真实Token；云端兼容接口须显式启用。provider错误、读取失败和无完整结束标记不视为成功，长度上限单独提醒。估算用量明确标记；失败用量未知不编造。

## Agent与记忆

react_loop.py自写行动解析、工具校验、Observation、继续/结束、重复与预算终止；原生assistant/tool调用对与JSON行动均可兼容。八工具注册且输入校验；计算器使用受限AST。

独立工具用受限线程池。线程超时不假装取消，仍占用原线程；只有已经返回的明确临时错误可最多重试两次，部分答案不重放。比较失败可转逐篇RAG，元信息失败转目录消歧。

记忆按工作区/会话隔离，保存近轮窗口及有预算的早期对话摘录，原始历史仍可查看；摘要作为背景，不是原文证据。窗口Token保守估算，模型用量另计。

## 接口

数据接口使用 X-Workspace-Token，16–128位字母、数字、下划线或横线。前端生成随机UUID，可保存恢复知识库。它是本地隔离凭据，不是公网完整登录系统；默认只绑定localhost。健康接口不返回其他用户scope。

| 接口 | 用途 |
| --- | --- |
| POST /documents | multipart files；最多20份、单份50MB、批次200MB |
| GET /jobs/{id} | queued/running/done/error、阶段、进度、失败 |
| GET /documents，GET/DELETE /documents/{id} | 列表、详情、一致性删除 |
| POST /documents/{id}/retry、/reindex | 失败重试、重新索引，返回任务 |
| GET /documents/{id}/file、/preview | 原件；page/chunk_id的PNG预览 |
| GET/POST /sessions，GET/DELETE /sessions/{id} | 会话管理 |
| POST /sessions/{id}/chat | message、document_ids、retrieval_mode、agent；SSE |
| GET /runs，GET /runs/{id} | 摘要和完整真实轨迹 |
| POST /experiments | JSONL file、mode、split；异步实验记录 |
| GET /experiments，GET /experiments/{id} | 状态与结果 |
| GET /experiments/{id}/export | format=json/csv/xlsx |
| GET /health，GET /config | 存活/就绪、无密钥配置 |

SSE数据为JSON：status、tool_start、tool_end、citation、answer_delta、usage、done、error。done给答案、证据、指标、审校。复杂工具结果分片标记replay，区别于模型原生传输。

## 配置与复现

config.yaml可被RAG_字段名大写环境覆盖。.env.example仅示例，不自动读入开启云端。RAG_PROFILE=demo显式检查流程。模型离线加载只访问本地缓存，下载由prepare_models显式执行。

评测保存语料、题集、配置hash、索引版本、包版本与可获取revision。扫描只允许dev且创建独立索引；最终test如果参与优化，必须标已暴露。真实评测与人工评分不以示例数据替代。
