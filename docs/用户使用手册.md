# 智能科研助理用户使用手册

更新日期：2026 年 10 月 10 日。

本机已准备本地模型与真实论文语料，标准工作区有10篇已就绪论文、359个检索片段。已有服务可直接打开 `http://127.0.0.1:8501`，需要启动时按 README 执行 `scripts/start.ps1 -Profile standard`；标准配置使用 BGE-M3 检索和本地 Qwen2.5 7B Q4 模型。功能演示模式使用哈希向量与原文抽取，界面会明确标识，演示结果不能作为正式模型质量数据。侧栏“API 已连接”与“模型与索引已就绪”表示不同阶段。

## 工作区保存与恢复

打开侧栏“工作区设置与恢复”，可以“保存当前工作区配置”、上传配置后“恢复配置文件”，或填写服务地址与工作区标识并点击“连接此工作区”。保存的配置用于恢复同一服务器上的论文和历史记录，请自行保管。

切换工作区会清理当前页面的论文选择、预览、任务与记录状态，避免混用资料。服务暂时离线时，可修复地址或重新启动服务，再点击侧栏“刷新连接”；资料与历史仍保存在后端。

## 论文库

在“上传研究资料”中选择 PDF、Word、TXT 或 Markdown，点击“导入所选资料”。单文件上限 50MB，每批最多 20 份、总计 200MB；任务显示真实处理阶段。重复内容复用已有文档，失败时显示原因并允许“重试导入”。

用“查找论文”和“文档状态”筛选资料，再从“查看文档详情”选择一篇。可“下载原件”“加入问答范围”“重建索引”或“删除文档”；删除需在确认窗口再次确认。加入的论文切换页面后仍保留。

详情包含三个页签：

- **原文预览**：PDF 可用上一页、下一页或物理页码浏览；“刷新原页”重新读取当前页。页码是 PDF 物理页，不一定等于论文印刷页码。其他格式通过原件与段落证据阅读。
- **论文信息**：核对标题、作者、年份、DOI、来源、别名与摘要，点击“保存元信息”。作者可每行一位，未知年份可留空清除错误值；人工核对的信息在重建索引后保留。
- **检索片段**：查看实际分块文本、页/段位置与策略，使用上一组、下一组浏览；“定位此片段原页”打开证据与原文窗口。

扫描 PDF 需要先 OCR。损坏或无法解读的 PDF 显示失败原因，不会把失败任务显示成成功。模型、分块或解析配置变更后，按提示重建相关文档索引。

## 科研问答

可“新建会话”，用“搜索会话”与“当前会话”切换历史；在“管理”中填写会话名称并“保存名称”，或导出 Markdown/JSON、删除会话。同名记录有独立标识，避免选错。

展开“论文范围与回答设置”，选择论文、检索方式及“启用多工具协作”。留空检索全部已就绪论文，也可“清空论文限定”。支持纯向量、混合、混合加重排序三档。论文限定会跨页面保留，并在切换会话时恢复该会话的范围。

提交具体问题后，页面显示真实阶段与流式答案。点击来源证据按钮打开“证据与原文”，核查摘录、物理页和定位区域，并可下载原始文档。“查看执行过程”恢复已经保存的工具与阶段记录，不会重新调用模型。

“请求停止”在可停止的事件边界生效，当前模型或工具调用可能仍需释放资源；已执行部分保存在运行记录。未完整结束的回答可以“重试上一次问题”，不会额外重复保存同一条未完成问题。普通模型补充回答、演示摘录和计算器结果会区分来源；无论文证据的回答不能直接当作论文事实。

## 论文对比

选择不同的“论文A”“论文B”，至少选择一个比较维度，再点击“生成证据对比”。相同论文或没有比较维度时不会提交。对比表保留两篇论文的来源；任务、数据集、划分、指标或实验条件不一致时，不直接计算优劣排名。

从“已保存的论文对比与多论文对话”恢复历史结果，下载对比 Markdown 或完整 JSON，必要时确认删除结果。切换页面后结果仍可恢复。

## 实验与运行记录

在“检索实验”中选择上传文件或“粘贴 JSONL”，选择开发集/测试集与检索模式，再“运行所选模式”或“依次运行三档对比”。题目须 `reviewed=true`，填写参考答案、真实文档 ID、页/段和原文摘录；未经核对或当前资料不存在的题目会拒绝提交。

等待任务成功完成后选择实验对比；语料、题集、划分或数据性质不同的结果不会绘制方法优劣图。打开“实验详情”查看实际指标，通过“单题排查”阅读返回片段、排名与标注原文，“打开此检索证据”可回到原页。结果支持 JSON、CSV、XLSX 下载，并可确认删除。演示模式会明确提示不能用于正式模型质量结论。

在“运行回放”中按问题或状态筛选，选择记录查看答案、来源、用量和“执行轨迹回放”。可以下载 Markdown/JSON、“打开对应会话”或确认删除记录；正在执行的记录可“请求停止当前执行”。回放读取保存的数据，不重新生成答案。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 服务未连接 | 检查服务地址和端口，必要时启动服务，再“刷新连接” |
| 模型或索引未就绪 | 查看健康面板；本机复用已准备模型，新电脑按 README 首次准备 |
| 找不到原有资料 | 恢复保存的工作区配置，核查连接的是原服务器 |
| 无法检索 | 等待文档就绪，查看失败原因，按当前配置重建索引 |
| PDF 无文字或损坏 | 扫描页先 OCR；损坏原件修复后重新上传 |
| 双栏、公式或表格失真 | 回到原页核查，并记录解析局限 |
| 问题超过上下文 | 缩短问题、新建会话或调整模型预算 |
| 评测拒绝 | 核对 reviewed、参考答案、文档 ID、页/段、摘录与数据划分 |
| 工具超过响应时间 | 查看运行记录；工作线程可能仍占用，等待释放后重试 |
| 已删除原件的历史引用 | 仍可查看保存的摘录，原页和原件下载可能不可用 |

自动证据审校检查引用与数值对应关系，关键事实仍需人工阅读原文。默认离线模式不发送资料到云端；显式云模式会发送所配置服务需要的上下文。界面验收范围及实际浏览器文件传输证据见[界面功能验收](界面功能验收.md)。
