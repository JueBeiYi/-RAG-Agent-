## 自动工作流

入口为 `scripts/check_ui_workflows.py`；旧入口 `scripts/smoke_ui.py` 是兼容薄包装，执行同一套测试。原 `--api` 参数继续可用；省略时自动启动独立随机端口的 demo API，不使用或停止已有服务。测试只操作自行创建的随机工作区，清理时不触碰真实语料与用户会话。

最新实际执行报告：[workflow-tests-20261010.json](../reports/ui/workflow-tests-20261010.json)。2026-10-10通过旧入口实际复跑，包含新浏览器会话恢复的16项工作流全部通过，退出码0；逐测试调用耗时合计46.69秒，不含环境初始化与清理。上一日记录保留在 [workflow-tests-20261009.json](../reports/ui/workflow-tests-20261009.json)。每份报告记录真实执行时间、退出码、逐项结果和测试限制。

| 工作流 | 核查内容 |
| --- | --- |
| 1. 会话管理 | 新建、重命名、搜索、切换、JSON/Markdown 导出、确认删除 |
| 2. 论文库完整流程 | 编辑标题/作者、清除未知年份、搜索、实际片段、物理页2图片、重运行后预览保留、原件下载、重建保留人工修正、失败重试与删除 |
| 3. 科研问答与隔离 | 选择论文、真实引用、证据原页、历史工具轨迹、跨页面保留选择、清空限定、切换工作区无旧资料混用 |
| 4. 对比持久化 | 两篇独立证据、离开页面后恢复、JSON/Markdown 导出 |
| 5. 三档评测与单题 | 未核对题目拒绝；纯向量、混合、混合加重排实际执行；结果与单题证据原页；JSON/CSV/XLSX 导出、实验删除 |
| 6. 运行记录与连接 | 回放答案/轨迹、导出、打开原会话、搜索/筛选、确认删除、服务离线友好显示及恢复 |
| 7. 真实 HTTP 完整合约 | 上传/索引、PDF 两页、片段、坏PDF详情200/预览400、年份清空、自定义会话名称保留、来源范围、评测拒绝/导出与隔离 |
| 8. 取消合约 | 不同工作区不能查看或取消活请求；当前工作区可以停止；已执行记录保留、会话锁释放、后续问题继续执行 |
| 9. 界面取消与重试 | 活请求期间输入禁用、界面停止、恢复输入、重试不额外重复保存未完成问题 |
| 10. 不同题集拒绝比较 | dataset_hash 不同时显示提醒且不绘制方法优劣图 |
| 11. 不同语料拒绝比较 | corpus_hash 不同时显示提醒且不绘制方法优劣图 |
| 12. 不同划分拒绝比较 | split 不同时显示提醒且不绘制方法优劣图 |
| 13. 同名论文不串项 | 同名文档和问答多选项仍可选择正确ID，多次重运行保持选择 |
| 14. 对比提交边界 | 同一篇论文或空比较维度禁用提交，不创建空会话/运行记录 |
| 15. 回答设置生效 | 纯向量设置体现在真实检索记录；关闭Agent无工具动作，开启后实际调用计算器 |
| 16. 新浏览器恢复论文范围 | 从后端会话恢复保存的论文限定，第一次加载不会丢失；已有论文库手动选择仍保持 |

测试使用 Streamlit AppTest 驱动真实控件，后端为实际 HTTP API。图片断言检查实际图片元素，上传、预览和导出内容另外通过 HTTP 字节与格式检查。AppTest 不模拟系统文件选择器和浏览器下载管理器；取消时序使用仅测试服务中的有界暂停，不冒充真实模型响应时间。
