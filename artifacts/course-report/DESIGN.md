# 课程报告图表设计与统计说明

本轮更新日期：2026-10-17。图表从冻结的 `data/report-data.json` 重绘，不新增模型调用，不改变原始实验记录。参考文件仅用于借鉴图形组织、配对展示和多面板布局，其论文数、题集、分数及实验结论未迁入本报告。

## 视觉规则

- 科学图采用白底、低对比辅助网格、左对齐标题及实验口径副标题，使用 A–D 面板编号建立阅读顺序。
- 检索方法的颜色固定：Dense 深蓝 `#193A56`、Hybrid 青绿 `#168980`、Rerank 赭金 `#C7923A`。其他颜色仅用于不同指标、对比方向或异常类别，并在图中标明。
- 箱图同时显示真实测量点；离散评分以档位、计数或气泡面积表达；热图标注量纲和数值，不将缺失值改写为零。
- 全部21幅科学图提供矢量 PDF、SVG 和400 dpi PNG。表格统一淡色表头、三线规则、留白及小数精度；粗体只比较同一实验条件下可比的指标。
- 五幅界面图保留真实页面及时间边界，外部标注不修改原始截图内容。

## 新增分析

| 图件 | 分析对象 | 方法与解释范围 |
| --- | --- | --- |
| `fig18_paired_effects` | 三种检索模式的60道相同测试题 | 以题号为配对单位，共用抽样索引，10,000次 Bootstrap，种子20261017；展示均值差及95%百分位区间。区间描述固定语料与标签下的查询抽样波动，不代表重复运行方差。 |
| `fig19_rank_matrix` | 每题首个相关证据的排名 | 按题型分面，显示三种方法的原始名次；Top20未找到以灰格和短横线表示，不作为名次0。 |
| `fig20_quality_association` | 60个回答的四维 AI 辅助评分 | 显示离散分数组合计数和处理并列秩的 Spearman 相关；不做连续密度平滑，不据此推断因果或独立人工一致性。 |
| `fig21_prompt_pairs` | 四道开发题的新旧 Prompt | 相同冻结上下文下逐题配对；新 Prompt 回答复用既有参数基线，展示平均变化及个体差异，不将四题探索性结果推广至总体。 |

两张新增表分别列出九项方法间配对效果及四类题型的四维评分均值。Hit@5、Recall@5 的表内差值使用百分点；MRR 使用原量纲。图18三项指标均使用0–1原量纲差值，单位在图、表及正文中分别注明。

## 可复现入口

`figure_style.py` 负责视觉规范，`build_figures.py` 重建全部图件，`build_advanced_figures.py` 计算新增统计，`build_report.py` 生成正文及表格。新增统计保存在 `data/advanced-statistics.json`，图件来源与参数保存在 `figures/figure_manifest.json`；最终文件指纹保存在 `package-manifest.json`。
