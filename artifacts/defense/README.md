# 课程设计答辩

[打开图表优化版答辩PPT](课设答辩_智能科研助理_图表优化版.pptx)

本版依据最新课程报告与冻结实验记录制作，共24页，采用16:9宽屏。

- 第1–18页为主体，建议按10–12分钟演练。
- 第19–24页为备答，补充切分策略、生成参数、题型与逐题检索对照、复现环境和团队信息。
- 24页均有讲稿、数据来源和解释范围备注，可在PowerPoint的备注或演示者视图中查看。
- 复用报告12幅学术图，采用原始高分辨率PNG与PowerPoint原生裁剪，图内数据不可直接编辑。
- 原生文字、架构图、1幅原生图表和4张表格可编辑。原生图表可以通过“编辑数据”调整。
- 真实界面截图保留在对应功能页，并注明历史时间。本地验收与历史检索实验分别说明口径。

核心内容包括文档处理、混合检索、手写Agent、来源回查、检索质量与时延、AI辅助评分、Prompt比较、Bad Case、本地验收以及版本感知记录。

评分始终标为AI辅助评审，未表述为独立人工盲评。Docker未作实际验收。原始实验数据保持不变，来源见每页备注及课程报告。

[原22页答辩稿](课设答辩_智能科研助理.pptx)作为历史版保留。历史交付快照中的 `artifacts/delivery-final/演示PPT.pptx` 也保留原版本；当前入口为上述24页图表优化版。
