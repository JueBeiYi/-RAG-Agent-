# 课程设计答辩

[打开答辩PPT](课设答辩_智能科研助理.pptx)

本版依据最新课程报告与冻结实验记录制作，共22页，采用16:9宽屏。

- 第1–18页为主体，建议按10–12分钟演练。
- 第19–22页为备答，包含开发集对照、生成参数、复现环境、团队信息与常见问题。
- 每页备注包含讲稿、数据来源和解释范围，可在PowerPoint的备注或演示者视图中查看。
- 文字、架构图、6幅数据图表和9张表格可编辑。数据图表附带内嵌工作簿，可以使用“编辑数据”调整。
- 真实界面截图保留在对应功能页，并注明历史时间。本地验收与历史检索实验分别说明口径。

核心内容包括文档处理、混合检索、手写Agent、来源回查、检索质量与时延、AI辅助评分、Prompt比较、Bad Case、本地验收以及版本感知记录。

评分始终标为AI辅助评审，未表述为独立人工盲评。Docker未作实际验收。图表在导出到内嵌工作簿时保留12位有效数字，超出页面显示精度；原始实验数据保持不变，来源见每页备注及课程报告。

历史交付快照中的 `artifacts/delivery-final/演示PPT.pptx` 保留原版本；本目录为当前答辩稿。
